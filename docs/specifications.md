# 仕様

worktree-cleaner はローカルの Git リポジトリに登録された linked worktree を列挙し、リポジトリ名、パス、判定、理由を表示する。
探索の起点はカレントディレクトリまたは `--root` で指定したディレクトリとする。
リポジトリ内ならそのリポジトリを、リポジトリ外なら直下の主 worktree を調べる。
登録先が起点の外でも判定対象に含める。

既定の削除候補は、基準ブランチに取り込まれたローカルブランチ上の clean な linked worktree とする。
基準は各リポジトリの origin/HEAD に対応するローカルブランチ、または `--base` で指定したローカルブランチとする。
ロック、作業中の変更、無視ファイルを含む未追跡ファイル、入れ子のリポジトリ、サブモジュール、進行中の Git 操作があれば保持する。
主 worktree、基準ブランチ自身、現在地を含む worktree、判定に失敗した worktree も保持する。

既定では一覧を表示する。
`--remove PATH` は探索範囲内の一件、`--remove-all` は探索範囲内の全候補について削除直前に再検査し、候補の作業ディレクトリと登録を削除する。
ブランチ参照は保持する。
再検査から削除が終わるまでは、対象での並行作業を止める必要がある。
判定条件とテスト設計は [ADR 0001](adr/0001-worktree-cleanup.md) に記載する。

`--include-unmerged` は、未マージの HEAD を同じローカルブランチで保持でき、ほかの保護条件を満たす worktree を候補に加える。
削除直前にブランチ名とコミット ID を照合し、削除後もブランチを保持する。
追加条件は [ADR 0002](adr/0002-include-unmerged-worktrees.md) に記載する。
